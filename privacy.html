PRIVACY

Privacy should be understandable.

This page states the current privacy posture for the Soheili Labs portfolio site and points users to product-specific policies where appropriate.

SoheiliLabs.com

The portfolio site is designed to collect as little personal information as practical. If analytics are added, this policy should be updated to name the provider and the data collected.

ClipKeep

ClipKeep is designed around local clipboard-history storage on the user's Mac. Sensitive-app exclusions and pause controls reduce capture risk, but no clipboard manager should be described as guaranteeing that sensitive content can never be captured.

AgencyOS

AgencyOS is a separate web application and should maintain its own product-specific privacy policy covering accounts, application data, cookies, hosting, and other services it uses.

Contact

Privacy questions can be sent to privacy@soheililabs.com. Replace or remove this address if that mailbox is not created.
